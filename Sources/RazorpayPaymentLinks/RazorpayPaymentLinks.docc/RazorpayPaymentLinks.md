# ``RazorpayPaymentLinks``

Payment Links: create, fetch, list, update, cancel and resend.

## Overview

Add the product and import it next to `RazorpayCore`:

```swift
.product(name: "RazorpayPaymentLinks", package: "razorpay-kit")
```

```swift
import RazorpayCore
import RazorpayPaymentLinks
```

`import RazorpayKit` includes this module too.
