# ``RazorpayRoute``

Route: transfers, reversals, linked accounts and stakeholders.

## Overview

Add the product and import it next to `RazorpayCore`:

```swift
.product(name: "RazorpayRoute", package: "razorpay-kit")
```

```swift
import RazorpayCore
import RazorpayRoute
```

`import RazorpayKit` includes this module too.
