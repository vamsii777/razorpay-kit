# ``RazorpaySubscriptions``

Plans and subscriptions.

## Overview

Add the product and import it next to `RazorpayCore`:

```swift
.product(name: "RazorpaySubscriptions", package: "razorpay-kit")
```

`import RazorpayKit` includes this module too.
