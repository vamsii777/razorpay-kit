# ``RazorpayCustomers``

Customers and their bank accounts.

## Overview

Add the product and import it next to `RazorpayCore`:

```swift
.product(name: "RazorpayCustomers", package: "razorpay-kit")
```

```swift
import RazorpayCore
import RazorpayCustomers
```

`import RazorpayKit` includes this module too.
